The Access controller is Sony's adjustable input device for the PlayStation 5.
Instead of a fixed stick-and-buttons layout, it ships with swappable caps and
mounting options so the device can be positioned around the player rather than
the other way round. This sample shows the basic setup flow, from the first
cable to a saved button layout.

## What is in the box

The kit includes the main unit, several stick caps and button caps in different
shapes, and a set of mounting plates. Everything is designed to be rearranged:
players can use a single controller, pair two together, or mix an Access
controller with a standard DualSense. Sony documents the full contents on the
[official Access controller page](https://www.playstation.com/en-us/accessories/access-controller/).

## Connecting it for the first time

1. Plug the controller into the PS5 with the included USB cable to pair it.
2. Open **Settings**, then **Accessories**, and confirm the device is listed.
3. Once paired over USB, you can switch to Bluetooth for wireless play.
4. Update the controller firmware if the console prompts you.

## Swapping inputs and saving layouts

The important part of the setup is remapping. In the accessories menu you can
assign any physical input to any DualSense button, so a single large cap can
act as the circle button while another cap handles the touchpad. Layouts are
saved as profiles, which matters if more than one person uses the same console:
switching profiles takes a few seconds instead of rebuilding the mapping each
time.

## Things to check before you buy

Game support varies. The controller emulates a standard DualSense, so most
titles work, but games with complex input schemes may still be awkward to play.
Check the accessibility options of the games you actually intend to play, and
see the broader [PlayStation 5 background here](https://en.wikipedia.org/wiki/PlayStation_5).
