## What happened

Square Enix is investigating a bug in a Nier: Automata update on PC that pushed the game's required install size from about 50GB to 366GB. The update arrived on November 6 and added Simplified Chinese, Traditional Chinese and Korean language support. It is not optional.

Square Enix confirmed the problem: after the update, the Steam installation process asks for far more storage space than intended. The company apologized to affected players in a post on the official Japanese Nier: Automata account and said it is investigating the cause and working on a solution.

## Why gamers should care

Steam demanded 366GB of free space to install a game that takes up roughly 50GB. Players reported that Steam is counting the full size of the base game for each DLC, and the cause is reportedly a bug affecting the DLC in the YoRHa Edition. Each DLC appears to match the base game's size when it is selected for download.

The inflated figure only applies to the initial download and installation. Once the game is installed, its size reportedly drops back to roughly 50GB.

## The temporary workaround

Square Enix suggested that anyone who needs to download the game deselect all eight DLC as a temporary fix. In Steam, that means opening the game's Properties menu, selecting DLC and unchecking the listed content. Doing so lets players install the base game without facing the inflated storage requirement.
